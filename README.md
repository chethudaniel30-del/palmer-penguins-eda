# Palmer Penguins: Exploratory Data Analysis and Visualization

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Palmer Penguins dataset using Python. The analysis explores penguin species, physical measurements, distributions, and relationships between numerical features through statistical summaries and data visualizations.

## Dataset

The Palmer Penguins dataset contains 344 observations and 8 columns.

**Features include:**
- Species
- Island
- Bill length and depth
- Flipper length
- Body mass
- Sex
- Year

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset inspection and descriptive statistics
- Missing-value analysis
- Species and island distribution analysis
- Numerical feature distribution analysis
- Species-wise measurement comparisons
- Correlation analysis
- Island-wise body mass comparison

## Visualizations

Eight visualizations were created, including:
- Species distribution bar chart
- Body mass distribution histogram
- Body mass comparison by species
- Flipper length box plot
- Flipper length versus body mass scatter plot
- Correlation heatmap
- Bill length comparison by species
- Species distribution across islands

## Key Findings

- Gentoo penguins have the highest average body mass and flipper length.
- Chinstrap penguins have the highest average bill length.
- A strong positive correlation (approximately 0.87) exists between flipper length and body mass.
- Species distribution varies across the three islands.

## Repository Contents

- `Penguins_EDA.ipynb` – Jupyter Notebook containing the analysis and Python code.
- `penguins.csv` – Dataset used for the analysis.
- `Penguins_EDA_Visualization_Report.docx` – Detailed project report.

## Project Objective

The objective is to demonstrate the use of Python libraries for data exploration, statistical analysis, visualization, and interpretation of patterns in a real-world dataset.
